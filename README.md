# PowerShell System Audit Tool

## Overview

A PowerShell automation project designed to perform Windows system health checks and generate reports for system administrators.

## Features

- Retrieve Windows operating system information.
- Monitor disk storage and available capacity.
- Identify drives with less than 20% free space.
- Retrieve installed physical memory.
- Identify stopped Windows services configured for automatic startup.
- Export disk information to CSV.
- Generate a formatted HTML system audit report.

# How to Run

1. Download the repository.
2. Open the project in VS Code.
3. Launch a PowerShell terminal.
4. Execute .\SystemAudit.ps1.
5. Review the generated SystemReport.html and DiskAudit.csv files.
